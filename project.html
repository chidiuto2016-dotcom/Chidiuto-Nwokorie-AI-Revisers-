FEATURED PROJECT / DATA MINING & AI

Boston Housing
KNN Prediction

Using Altair AI Studio to apply K-nearest neighbors to a housing-price prediction problem.

PROJECT OVERVIEW

From housing data to a prediction.

The project uses the BostonHousing dataset to predict MEDV, the median value of owner-occupied homes. The assignment required using the first 12 columns as predictors and excluding the derived CAT.MEDV field.

I built the workflow in Altair AI Studio, used K-nearest neighbors as the modeling approach, applied the trained model to an example set, and evaluated model performance using root mean squared error (RMSE).

01 / PROCESS

A repeatable modeling workflow.

01

Prepare

Load the BostonHousing data and identify MEDV as the target while excluding CAT.MEDV.

02

Configure a K-nearest-neighbors model and select the K value used for prediction.

03

02 / TECHNICAL DETAILS

What the project demonstrates.

Tool Altair AI Studio
Algorithm K-nearest neighbors (KNN)
Target MEDV — median home value
Predictors First 12 data columns from the assignment
Evaluation Root mean squared error (RMSE)

03 / WHAT I LEARNED

The workflow matters as much as the model.

This project reinforced that a prediction is not just the final number. The data must be prepared correctly, the target and predictors must be identified correctly, the model must be configured, and the result must be evaluated. Building the process visually in AI Studio made each step easier to inspect and troubleshoot.

K Key takeaway

Good data preparation and a clear modeling workflow make technical results easier to understand and reproduce.
