# Chidiuto Nwokorie — Personal Portfolio

A recruiter-focused personal website for the ISDS 3100 AI Lab: Vibe Coding and Agent Skill Development assignment.

## Project description

This site presents my background as an LSU Information Systems and Decision Sciences student. The homepage is a single-page hub containing my **Profile, Skills, Experience, and Contact** sections. Two separate pages expand the hub:

- `resume.html` — education, experience, coursework, and skills
- `project.html` — a featured Boston Housing KNN data-mining project using Altair AI Studio
- `styles.css` — shared responsive visual system
- `favicon.svg` — lightweight site icon

The site uses Foundation for its responsive grid/layout foundation and custom CSS for the visual identity and page design.

## Reflection

One specific thing I learned from directing an AI coding agent is that giving a broad instruction such as “make a portfolio” is not enough to produce a submission that matches a rubric. I learned to break the requirements into concrete acceptance criteria: exact filenames, required sections, working links, responsive behavior, accessibility features, consistent styling, and a README reflection. That made the development process more structured because I could review the generated code against the assignment instead of judging the site only by how it looked.
